# 言寺日程

## 软件概述

言寺日程 V1.0 是一款用于个人日程整理的中文软件，主要帮助用户把每天、每周和每月的安排放在同一个界面里查看、录入和维护。软件保留本地优先的使用方式，适合记录课程、值班、会议、运动、提醒事项等带时间段的安排，也适合把经常重复出现的内容做成模板，减少重复填写。

软件界面分为周视图、月视图和管理区域三部分。周视图更接近课程表，适合按时间段安排任务；月视图适合观察整个月的密度和空档；管理区域用于维护色签、模板和本地数据。桌面端保留侧边管理区，移动端则把管理入口收进顶部的“管理”按钮里，点开后以居中的浮窗显示，方便在手机上使用。

## 运行环境与启动

软件可在 Windows 桌面环境和 Android 手机上使用。桌面端以 Tauri 方式运行，手机端使用 Android 封装后的应用打开。用户启动后会看到主界面和当前日期对应的日程视图，无需先创建账户，也不需要额外登录。

在桌面端，用户可直接打开程序并进入周视图或月视图；在移动端，首次进入时顶部会显示品牌、日期和管理入口，底部提供添加日程和批量添加的快捷按钮。软件的数据默认保存在本地，关闭后再次打开仍能看到上次保存的内容。

## 主界面和日期导航

软件顶部工具栏用于切换周视图和月视图，也用于定位日期。用户可以点击“今天”回到当前日期，点击前后切换按钮查看上一周、下一周、上一个月或下一个月。周视图标题会显示当前周的日期范围，月视图标题会显示当前月份，便于用户快速确认自己正在查看的时间段。

在桌面端，工具栏下方会同时显示日程主视图和管理区域；在移动端，主视图优先占满屏幕，管理入口收在右上角，避免占用过多空间。用户如果只想看当天的内容，可以先在工具栏定位日期，再进入对应的周视图或月视图查看当天安排。

## 周视图查看日程

周视图用于按时间段查看一周内的安排。界面左侧是时间轴，右侧是每天的日程列。用户可以直接看到某一时段是否已经安排了内容，也可以比较相邻几天的时间密度。对于需要按课表、排班表或者固定时间块安排工作的场景，周视图最直观。

当用户点击某个空白时间段时，软件会直接打开新建日程窗口，并把点击位置对应的日期和时间带进去。用户也可以点击某一条已有日程进入编辑状态，查看标题、备注、颜色和时间范围，然后按需要修改。若同一天出现时间重叠，软件会在保存时提醒冲突并拒绝继续保存，避免把冲突安排写进日程表。

## 月视图查看日程

月视图以整月网格展示日期，适合快速查看整个月的安排分布。用户可以从月视图里看到哪些日期已经排满，哪些日期还有空余，也可以直接点选某一天查看当天的全部日程。单日事项较多时，日期格内会保留滚动空间，用户不需要离开月视图就能看到当天的主要内容。

月视图更适合做整体检查。比如用户想确认某一周是否太满、某个周末是否留出了休息时间，或者某一天是否已经安排了太多事项，都可以先在月视图中完成初步判断，再进入单个日程做调整。

## 新增、编辑和删除日程

新建日程时，用户需要填写标题、日期、开始时间、结束时间、颜色和备注。标题用于识别这条安排，日期和时间用于定位具体时段，颜色则用于区分类别，备注可以写提醒内容、任务说明或者当天需要注意的事情。填写完成后点击保存，软件会把这条日程加入列表。

编辑日程时，用户先点击已有日程，再在弹窗里修改内容。常见的修改场景包括调整开始和结束时间、补充备注、替换颜色或者更换标题。如果某条日程不再需要，用户也可以直接删除。删除后该条记录会从当前视图和列表中移除，后续查看时不会再显示。

保存过程中，软件会检查同一天是否存在时间段冲突。如果新填的时间和已有日程重叠，界面会提示用户调整时间后再提交，这样可以避免同一时间段出现两条无法同时执行的安排。

## 批量添加日程

批量添加适合一次录入多条类似安排，例如一周课程、连续排班、多个固定会议或者一组训练计划。用户打开批量添加窗口后，可以逐行填写标题、备注、日期、开始时间和结束时间。每一行都是独立日程，最后统一保存。

这个功能的价值不在于一次填很多字，而在于减少重复操作。用户如果需要连续录入多条时间接近、内容相似的事项，可以先建好第一条，再按行补充其他日期或时间。保存时，软件会逐条检查冲突；某一行有问题时，用户可以先返回修改该行，不影响其他已填写内容。

## 模板管理

模板用于保存用户经常重复使用的日程内容。常见内容例如“值班”“上课”“运动”“阅读”等，通常标题、颜色和备注都比较固定。用户把这些内容保存成模板后，下次新建日程时可以直接点选模板，软件会自动带出标题、颜色和备注，减少重复输入。

模板管理适合高频使用场景。比如每周固定几次的课程、每晚固定的学习计划、长期保留的作息安排，都可以放进模板里。用户只需要在创建日程时选择合适的模板，再补充日期和时间即可。

## 色签管理

色签用于给日程和模板做颜色分类。软件内置了常用颜色，用户也可以输入自定义 HEX 颜色，满足不同分类习惯。比如工作事项可以用一种颜色，学习事项用另一种颜色，个人安排再用另一种颜色，这样在周视图和月视图里更容易一眼区分。

用户在色签管理里新增标签后，后续创建日程或模板时就可以直接选择对应颜色。色签本身不改变日程内容，但会影响界面上的展示方式，让同类事项更好辨认。对于安排较多的人来说，这个功能能明显提升浏览速度。

## 数据导入导出

数据导出用于把当前日程备份成 JSON 文件。用户在更换设备、重装软件或者需要保存副本时，可以先导出备份文件，再在其他设备或后续时间导入恢复。导入时选择 JSON 文件即可，软件会把文件里的日程重新写入本地数据。

这个流程适合做本地备份，也适合在桌面端和移动端之间迁移内容。由于软件采用本地优先方式运行，导出后的文件就是用户自己的备份，恢复时不依赖网络，也不需要额外账号。

## 移动端使用说明

移动端界面针对小屏幕重新排布。顶部保留品牌和日期，右侧是“管理”入口，底部保留添加日程和批量添加按钮。用户在手机上查看日程时，不需要去找侧边栏，常用操作都能在首屏完成。

点开“管理”后，界面会在中间弹出管理浮窗，里面分为色签、模板和数据三个入口。用户可以在手机上直接维护常用内容，也可以导入或导出备份文件。为了避免内容和状态栏重叠，移动端顶部预留了安全区，界面在不同手机上也能保持可读。

## 常见提示与注意事项

如果保存时提示时间冲突，说明同一天已经有重叠安排，用户需要先调整开始或结束时间。若用户想录入大量类似内容，建议先创建模板，再通过批量添加补充日期和时间，这样操作更快，也更不容易填错。

数据导入时要使用软件导出的 JSON 文件或符合格式的备份文件。如果文件内容不完整，软件会提示导入失败。导出文件建议妥善保存，便于后续恢复。移动端使用时，如果顶部内容较多，建议先切换到需要查看的日期范围，再进入具体日程编辑。

## 典型使用流程

1. 用户打开软件，先在周视图查看当前日期附近的安排。
2. 用户通过工具栏切换到月视图，确认整月的忙闲分布。
3. 用户点击空白时间段或添加按钮，新建一条日程。
4. 用户填写标题、日期、时间、颜色和备注后保存。
5. 用户在需要时打开日程进行编辑，或直接删除不再需要的内容。
6. 用户将常用内容保存成模板，后续创建时直接复用。
7. 用户在色签里维护颜色分类，方便区分不同类型事项。
8. 用户在数据管理中导出备份，或从备份文件导入恢复。
