# 业务理解

- 软件名称：言寺日程
- 产品定位：言寺日程是一款面向个人和小团队的本地优先中文日程管理软件，提供周视图、月视图、日程新增编辑、批量添加、模板复用、色签分类和数据备份恢复等功能，并支持桌面端与 Android 移动端使用。
- 面向领域 / 行业：个人效率与日程管理软件
- 核心价值：通过清晰的日历视图、本地化数据管理和可复用模板，帮助用户把分散的时间安排整理成可查看、可编辑、可备份的日程计划，减少时间冲突和重复录入。
- 证据文件：`业务理解证据.md`

## 目标用户

- 需要按周或按月整理时间安排的个人用户
- 需要记录课程、值班、运动、会议等固定或重复安排的学习和办公人群
- 希望数据保存在本地并可自行导入导出的用户
- 同时需要桌面端和移动端查看日程的用户

## 主要业务功能

- 周视图日程查看
- 月视图日程查看
- 日程新增、编辑与删除
- 批量创建日程
- 时间冲突检测
- 模板管理与快速套用
- 色签管理与颜色分类
- 本地数据导入导出
- 桌面端与移动端适配

## 功能说明

- 周视图日程查看：软件以课程表式周历展示一周内的安排，用户可以按日期和时间段查看事项，并可从周视图空白时间位置发起新建日程。
- 月视图日程查看：软件以整月网格展示日期和当天安排，用户可以选择某一天查看当天列表，适合观察月度安排密度和重点日期。
- 日程新增、编辑与删除：用户可以维护日程标题、日期、开始时间、结束时间、颜色和备注，已有日程可再次打开修改或删除。
- 批量创建日程：用户可以在同一弹窗中添加多行日程，分别填写标题、备注、日期和时间后一次保存，适合录入多段课程、值班或固定安排。
- 时间冲突检测：保存日程时，软件会检查同一天内时间段是否重叠，发现冲突时阻止保存并提示用户调整时间。
- 模板管理与快速套用：用户可以保存常用日程模板，模板包含标签、标题、颜色和备注；新建日程时可选择模板快速填充内容。
- 色签管理与颜色分类：用户可以使用预设颜色或自定义 HEX 颜色创建色签，并将色签用于日程和模板，便于区分不同类型安排。
- 本地数据导入导出：软件以本地优先方式保存日程数据，支持导出 JSON 备份文件，也支持从备份文件导入恢复。
- 桌面端与移动端适配：桌面端保留侧栏管理区，移动端使用紧凑顶部栏、底部快捷操作和管理浮窗，Android 端预留状态栏安全区。

## 典型操作流程

1. 用户进入软件后，默认看到当前日期所在的周视图，并可通过工具栏切换周视图和月视图。
2. 用户点击今天、上一周期、下一周期等控件定位需要查看的日期范围。
3. 用户在周视图或月视图中选择日期，查看当天已安排的日程列表。
4. 用户点击添加日程或在日历空白区域触发创建，填写标题、日期、开始时间、结束时间、颜色和备注后保存。
5. 用户点击已有日程进入编辑状态，修改内容后保存，或删除不再需要的日程。
6. 用户需要一次录入多条安排时，打开批量添加窗口，逐行填写标题、备注、日期和时间，确认后批量写入日程列表。
7. 用户在管理区域维护色签和模板，用于后续日程分类和快速复用。
8. 用户在数据管理中导出本地数据备份，或选择已有备份文件导入恢复。
